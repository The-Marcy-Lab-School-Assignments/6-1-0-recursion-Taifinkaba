What is a recursive function? What are "cases" that exist in recursive functions?

# Answer
recursive function is when a function loops itself till it meets the base case. The cases are: base case that it needs to fail and a way for the program to loop itself.

# Teacher Feedback

The two cases are the base case and the recursive case. The base case is typically an if statement that checks the smallest and most specific case. The recursive case comes into play when the base case is not met. It is what makes the function rerun itself until we reach that base case.
